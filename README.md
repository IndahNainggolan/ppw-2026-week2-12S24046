# ppw-2026-week2-12S24046

## Praktikum Minggu 3 - Bootstrap 5 & Modern Web Design

Portfolio pribadi yang dikembangkan menggunakan HTML5, CSS3, dan Bootstrap 5.3.

## Deskripsi

Website ini merupakan pengembangan dari portfolio pada praktikum sebelumnya.
Pada Minggu 3, website diperbarui menggunakan Bootstrap 5 untuk membuat tampilan
yang lebih responsive, modern, dan interaktif.

## Perubahan dari Minggu 2 ke Minggu 3

### Minggu 2
- Menggunakan HTML5 dan CSS3 secara manual.
- Layout dibuat menggunakan CSS.
- Navbar dibuat menggunakan CSS Flexbox.
- Form dibuat menggunakan HTML dan CSS.
- Tampilan responsive dibuat menggunakan media query.
- Belum menggunakan Bootstrap.

### Minggu 3
- Menggunakan Bootstrap 5.3 melalui CDN.
- Menggunakan Bootstrap Icons.
- Mengubah navbar menjadi responsive Bootstrap Navbar.
- Menambahkan hamburger menu pada layar kecil.
- Menggunakan Bootstrap Grid untuk layout portfolio.
- Menambahkan 4 kartu project.
- Menambahkan badge teknologi.
- Menambahkan modal untuk detail project.
- Memodernisasi form menggunakan Bootstrap.
- Menambahkan floating labels.
- Menambahkan input groups dengan ikon.
- Menambahkan validasi form.
- Menambahkan checkbox syarat dan ketentuan.
- Menambahkan CSS variables untuk mengatur tema.
- Menambahkan hover dan focus interaction.
- Menyesuaikan tampilan untuk desktop dan mobile.

## Teknologi yang Digunakan

- HTML5
- CSS3
- Bootstrap 5.3.3
- Bootstrap Icons
- JavaScript
- Git & GitHub
- Visual Studio Code
